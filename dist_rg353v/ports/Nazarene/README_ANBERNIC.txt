================================================================================
  THE NAZARENE: WAY OF THE CROSS - ANBERNIC RG-353V INSTALLATION GUIDE
================================================================================

Target Hardware: Anbernic RG-353V (Rockchip RK3566, 64-bit ARM Cortex-A55, Mali-G52 GPU)
Operating System: Default Anbernic Stock Linux OS (also 100% compatible with ArkOS, JELOS, ROCKNIX, AmberELEC, and PortMaster)
Display: 3.5-inch 640x480 IPS display (native locked 60 FPS integer-scaled arcade presentation)

--------------------------------------------------------------------------------
1. QUICK INSTALLATION (SD CARD COPY)
--------------------------------------------------------------------------------
Copy the "ports" directory from this package to your Anbernic SD card:

Option A - Single SD Card Setup (Slot 1 / TF1):
  Copy the "ports" folder into your ROMs partition so that:
    /roms/ports/Nazarene.sh
    /roms/ports/Nazarene/Nazarene.aarch64
    /roms/ports/Nazarene/Nazarene.gptk
    /roms/ports/Nazarene/gamecontrollerdb.txt
    /roms/ports/Nazarene/libs/libSDL2-2.0.so.0
    /roms/ports/Nazarene/assets/
    /roms/ports/Nazarene/title.jpg

Option B - Two SD Card Setup (Slot 2 / TF2 - Game Card):
  Insert your Game SD Card into your PC.
  Open the "ports" folder on the SD card (or create "ports" if not present).
  Copy:
    Nazarene.sh
    Nazarene/
  directly into the "ports" folder on the card.

--------------------------------------------------------------------------------
2. LAUNCHING THE GAME
--------------------------------------------------------------------------------
1. Insert the SD card into your Anbernic RG-353V and power on.
2. In EmulationStation, navigate to the "PORTS" menu.
3. Select "The Nazarene" and press A.
4. The game starts instantly at full speed (locked 60 FPS) with Capcom 16-bit
   visuals, procedural FM sound synthesis, and full handheld controls!

--------------------------------------------------------------------------------
3. CONTROLS ON ANBERNIC RG-353V
--------------------------------------------------------------------------------
  D-Pad / Left Stick : Move Left/Right, Crouch (Down), Look Up (Up)
  B Button / A Button: Jump / Somersault High Leap (Up + Jump)
  Y Button           : Melee Slash / Throw Holy Iron Spike
  X Button           : Divine Wrath (Holy Ninjutsu Full-Screen Board Wipe)
  L1 Shoulder Button : Divine Wrath (Alternative trigger)
  R1 Shoulder Button : Attack (Alternative trigger)
  L2 + R2 Triggers   : Secret Mission & Stage Select Menu (press both on Title)
  START Button       : Start Game / Confirm / Resurrect Continue
  SELECT Button      : Dual Function:
                       - On Title Screen: Insert Coin (Add Credit)
                       - During Gameplay: Instant Level Exit (return to Title)

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
  Mission 1: Jerusalem Campaign & Antonia Fortress (Centurion Brutus, Commander Malchus, Praetor Longinus)
  Bonus:     Feeding the 5,000 on Mount of Beatitudes
  Mission 2: Road to Gethsemane (Tormentor Decurion, Shadow Inquisitor, Christus Tenebris)
  Mission 3: Journey to the Upper Room & The Last Supper (Barabbas, Caiaphas, Judas Iscariot)
  Mission 4: The Judgment of Pontius Pilate (Prefect Quintus, Advocate Tertullus, Pontius Pilate)
  Mission 5: Mount Calvary / Golgotha Summit Climax:
             - Sequential Gauntlet: Green Hellfire Clone -> The Devil (Demon Tail Whip) ->

             - Angelic Ascension & Heavenly Skee-Ball Epilogue!
